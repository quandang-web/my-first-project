# Nhật ký Prompt - Tái cấu trúc Landing Page

## Quá trình thực hiện
- Sử dụng Semantic Tags (header, main, section, article, footer) để tối ưu cấu trúc cho SEO.
- Áp dụng chiến lược Atomic Commits (4 commits riêng biệt) để quản lý lịch sử dự án rõ ràng theo tiêu chuẩn Conventional Commits.

## Lịch sử tương tác
- Đã hỏi AI về sự khác biệt giữa `<article>` và `<section>` để phân loại dịch vụ chính xác.
- Đã hỏi AI cách cấu hình lại Git Local để trỏ về tài khoản GitHub cá nhân mới.
- Đã yêu cầu AI giải thích ý nghĩa của các tham số Git (như `-m`, `add`, `commit`).
